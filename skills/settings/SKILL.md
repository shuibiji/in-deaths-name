# 规则加载设置

以本文件所在目录为基准，定位 `../../scripts/in-deaths-name-settings.ts`，使用 `node` 执行该脚本。脚本路径应使用绝对路径并加引号，不依赖用户当前的工作目录。

- 用户提供次数时，将该值作为单独的命令行参数传入，不自行改写或猜测数值。
- 用户没有提供次数时，不传参数，只查看当前设置。
- `0` 关闭压缩后的自动重载，首次加载保留；正整数表示每隔多少次上下文压缩重新加载。`null` 等无效值由脚本报错，原设置保留。
- 根据脚本的实际输出报告结果。只处理这项设置，不改规则正文、Hook 配置或其他文件。
